# GameNight landing page

A static page (no build step): `index.html`, `favicon.svg` and the screenshots in `img/`.

Before deploying, set `GAME_URL` near the bottom of `index.html` to the game's address.

Deploy on Vercel: Add New → Project → import `jpcpais01/football-game`, set **Root Directory** to
`landing`, Framework Preset **Other**, leave the build command empty, Deploy.
